# 🚀 SkillForge AI

### Personal Skill & Career Development Platform

SkillForge AI is a full-stack web application built with **Python and Django** that helps students and developers identify their skill gaps, choose career goals, create personalized learning roadmaps, and track their learning progress.

The platform also allows users to maintain their professional projects and certifications in one place.

---

## 📌 Project Overview

Choosing a career path can be difficult when you don't know which skills you already have and which skills you still need to learn.

SkillForge AI addresses this problem by connecting:

**Career Goals → Required Skills → Current Skills → Skill Gap → Learning Roadmap → Progress Tracking**

Users can select a target career, add their existing skills, and analyze the skills required for their chosen career.

The system then identifies missing skills and creates a learning roadmap that users can follow and update as they progress.

## ✨ Features

### 🔐 User Authentication

- User registration
- User login
- User logout
- Secure authentication using Django
- Protected user-specific pages

### 👤 Personal Profile

Users can maintain:

- Education
- College
- Graduation year
- Career goal
- Personal bio

### 🛠️ Skill Management

Users can:

- Add technical skills
- Select skill levels
- View their skills
- Remove skills

Supported skill levels:

- Beginner
- Intermediate
- Advanced
